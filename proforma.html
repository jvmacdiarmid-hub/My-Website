Supported formats & tips
Excel (.xlsx) — any sheet with a column header row containing words like Name, Shares, Type, or Series. Labeled rows like Pre-Money Valuation: $10,000,000 are picked up for round config. Multiple sheets are all scanned.

Word (.docx) — values labelled in the document, e.g. Pre-money valuation: $12,000,000, Option pool: 15%, or lines like Founders 8,000,000 Common.

ZIP archive (.zip) — drop a zip containing an Excel or Word file. If multiple documents are inside, the first Excel file is used (or the first Word file if no Excel file is found).

After upload, review the preview and confirm before the form is populated. You can edit any value afterwards.
